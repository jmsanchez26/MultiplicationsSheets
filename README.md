# Multiplication Sheets

Ten multiplication worksheets (× 1 to × 10) for writing on with an Apple Pencil on an iPad.

- Hideable left sheet list, full-screen sheet when hidden
- Pen, eraser, ink colors, undo, clear
- Pencil draws; finger scrolls (optional "Finger draws")
- Ink is saved per sheet in the browser (localStorage)

Open `index.html` in Safari, or host it (e.g. GitHub Pages) and Add to Home Screen.
